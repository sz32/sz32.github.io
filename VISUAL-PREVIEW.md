## ✨ Animations

### On Scroll (AOS)
- Fade up
- Fade left/right
- Zoom in
- Delays: 100ms, 150ms, 200ms, etc.

### On Hover
- Cards: translateY(-5px) + shadow
- Buttons: translateY(-2px) + color change
- Links: color transition
- Tags: scale + shadow

### Interactions
- Smooth scroll (250ms ease)
- Menu transitions (300ms ease)
- Form states (150ms fast)
- Counter animations (2000ms)
