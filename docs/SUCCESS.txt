🎯 EXAMPLE EDITS:

  ► Change your name:
    Find: "profile" → "name"
    Edit: "name": "Your Name"

  ► Add a skill:
    Find: "skills" → "categories"
    Add: { "name": "New Tech", "items": ["Skill1"] }

  ► Add a project:
    Find: "projects" → "items"
    Add: { "name": "Project", "type": "regular", ... }

  ► Reorder sections:
    Find: "sectionOrder"
    Rearrange: Move items up/down in the array
