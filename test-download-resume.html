How to Use

Adding Your Resume URL

Open portfolio-data.json and add your resume URL to the profile section:

{
  "profile": {
    "name": "Zeel Solanki",
    "title": "Senior Software Engineer",
    "description": "Your description...",
    "resumeUrl": "documents/your-resume.pdf"
  }
}

Example URLs

Local File:

"resumeUrl": "documents/zeel-solanki-resume.pdf"

Google Drive:

"resumeUrl": "https://drive.google.com/uc?export=download&id=YOUR_FILE_ID"

External URL:

"resumeUrl": "https://your-website.com/resume.pdf"

To Hide the Button

Leave the URL empty:

"resumeUrl": ""

Features

  • ✅ Conditional display (only shows when URL is provided)
  • ✅ Download attribute (prompts browser to download)
  • ✅ Animated hover effects
  • ✅ Pulsing download icon animation
  • ✅ Mobile responsive
  • ✅ Secure (rel="noopener noreferrer")
