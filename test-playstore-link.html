How to Use in portfolio-data.json

Single App Example:

{
  "name": "Your App Name",
  "type": "regular",
  "description": "App description",
  "responsibilities": [
    "Feature 1",
    "Feature 2"
  ],
  "playstoreUrl": [
    {
      "label": "Your App Name",
      "url": "https://play.google.com/store/apps/details?id=com.yourapp.package"
    }
  ]
}

Multiple Apps Example (for SDK projects):

{
  "name": "Enterprise SDK",
  "type": "sdk-showcase",
  "description": "SDK used across multiple apps",
  "playstoreUrl": [
    {
      "label": "App One",
      "url": "https://play.google.com/store/apps/details?id=com.company.app1"
    },
    {
      "label": "App Two",
      "url": "https://play.google.com/store/apps/details?id=com.company.app2"
    },
    {
      "label": "App Three",
      "url": "https://play.google.com/store/apps/details?id=com.company.app3"
    }
  ]
}

Note: Use an empty array [] if the project is not on Google Play Store.
